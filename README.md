
# EAAI Model AI Assignment: AI for Menopause Education

This repository contains the materials for a model AI assignment for the EAAI (Symposium on Educational Advances in Artificial Intelligence). The assignment is focused on the development of an AI-powered educational tool for menopause.

## Repository Structure

- **`/Menopause-Education`**: This directory contains all the materials for the assignment, as per the EAAI submission guidelines.
  - `index.html`: A summary of the assignment and links to the materials.
  - `menopause.html`: An informational page about menopause.
  - `cultural_assessment_question_bank.html`: A question bank for cultural assessment.
  - `safety_validation_code.ipynb`: A Jupyter Notebook for safety validation.
  - `user_persona_template.md`: A template for creating user personas.
- **`/main_paper`**: This directory contains the LaTeX source for the accompanying research paper.

## About the Assignment

This assignment is designed to be a hands-on project for students to learn about the application of AI in a real-world context. It encourages students to think about the ethical implications of AI and the importance of human-centered design. The assignment can be adapted for various levels, from advanced undergraduate to graduate courses.

## Usage

To use this assignment, instructors can clone this repository and distribute the materials in the `/Shuvam-Menopause-Education` directory to their students. The `index.html` file provides a starting point for students to understand the assignment and access the materials.
